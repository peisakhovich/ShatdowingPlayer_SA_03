# Sound Language Studio
**Язык:** Русский | [English](index_en.md)
## Введение

### Что такое Sound Language Studio

**Sound Language Studio** — настольное приложение для изучения иностранных языков с использованием текстовых и аудио-тренировок.

Приложение объединяет работу с текстом, синтезом речи, воспроизведением аудио и интерактивным графическим интерфейсом. Учебный материал может автоматически преобразовываться в последовательность действий, образующих языковую тренировку.


### Назначение проекта

Основная задача Sound Language Studio — предоставить инструмент для самостоятельной практики иностранного языка, позволяющий создавать и выполнять различные виды тренировок на основе учебного материала.

Архитектура проекта построена с учётом возможности дальнейшего расширения. В частности, сценарий тренировки не является жёстко заданной частью программной логики. Последовательность действий определяется конфигурацией в файле `scenarios.json`.

Это позволяет изменять существующие сценарии и добавлять новые без изменения основной архитектуры приложения.

### Сценарно-параметрический конечный автомат

В качестве движка выполнения тренировок приложение использует **сценарно-параметрический конечный автомат**.

Сценарий определяет последовательность состояний и действий, которые должны выполняться во время тренировки, а параметры определяют конкретные данные и условия выполнения этих действий. В результате один и тот же механизм выполнения может обслуживать различные сценарии обучения.

Описание последовательности действий вынесено в `scenarios.json`. Благодаря этому логика выполнения тренировки отделена от конкретного сценария и его содержания.

Такой подход позволяет рассматривать тренировку как последовательность управляемых состояний, переход между которыми определяется сценарием и текущими параметрами. Добавление нового сценария в общем случае сводится к описанию соответствующей последовательности действий в конфигурации.

### Сценарии обучения

Сценарий обучения описывает последовательность действий, которые приложение выполняет при работе с очередной фразой.

В конфигурации сценария могут использоваться действия, например:

* `SHOW` — отображение текста;
* `HIDE` — скрытие элемента интерфейса;
* `PLAY` — воспроизведение аудио;
* `WAIT` — ожидание заданной паузы.

Действия могут обращаться к различным элементам учебного материала и параметрам тренировки, например `phrase_text`, `translate_text`, `pause_before_translation` и `pause_between_sentences`.

В текущей конфигурации `scenarios.json` предусмотрены следующие сценарии:

* **Shadowing**;
* **Shadowing without translation**;
* **Translation first**;
* **Reading**;
* **Dictation**.

Этот список не является фиксированным. Файл `scenarios.json` представляет собой механизм конфигурации, посредством которого набор сценариев может быть расширен или существующие сценарии могут быть изменены.

Таким образом, **Shadowing** является одним из сценариев приложения, а **Dictation** — отдельным сценарием, использующим общую инфраструктуру приложения.

### Основные возможности

На текущем этапе Sound Language Studio предоставляет следующие возможности:

* анализ и обработку учебного текста;
* определение языка текста;
* сегментацию текста на фрагменты;
* автоматическое формирование планов тренировок;
* синтез речи;
* кэширование аудио;
* воспроизведение аудио;
* выполнение конфигурируемых сценариев тренировок;
* работу с пользовательскими учебными наборами;
* импорт и экспорт учебных материалов;
* управление пользовательской сессией;
* авторизацию пользователей;
* взаимодействие с серверным API.

### Общая архитектура

Приложение состоит из нескольких основных подсистем:

* **AI** — определение языка, обработка текста, сегментация и формирование планов тренировок;
* **Audio** — синтез, кэширование и воспроизведение аудио;
* **GUI** — графический интерфейс пользователя;
* **Session** — управление пользовательской сессией и учебными наборами;
* **API** — взаимодействие с серверной частью;
* **Core** — основные компоненты приложения, конфигурация и системные службы;
* **Utils** — вспомогательные компоненты.

Отдельное место занимает механизм сценариев. Он связывает учебные данные с последовательностью действий, определяемой конфигурацией `scenarios.json`. Благодаря этому одна и та же программная инфраструктура может использоваться для различных форм языковых тренировок.

Подробное устройство отдельных подсистем, модулей и их API представлено в разделе **Modules**.
