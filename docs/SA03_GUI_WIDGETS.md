# SA_03 GUI Widgets

## Назначение

Набор собственных GUI-компонентов SA_03, независимых от сторонних GUI-библиотек. Все виджеты имеют единый жизненный цикл:

    handle_event() → update() → draw()

Каждый виджет отвечает только за собственное состояние и не содержит логики приложения.

---

## ImageButton

Назначение:
Кнопка с графическими изображениями.

Состояния:
- normal
- hover
- pressed

Возвращает:
- command (str) при успешном нажатии
- None

Используется:
- Панель управления
- Навигация
- Кнопки воспроизведения

---

## TextButton

Назначение:
Текстовая кнопка общего назначения.

Параметры:
- rect
- caption
- font
- auto_width

Состояния:
- normal
- hover
- pressed
- focused

Возвращает:
- True
- False

Используется:
- Dialog
- Будущие меню
- Панели настроек

## HorizontalSlider

Используется:

- Предупреждения
- Выбор пользователя

---

## Общие правила

Все виджеты:

• используют Theme;
• ничего не знают о MainWindow;
• ничего не знают о других виджетах;
• самостоятельно обрабатывают свои события;
• самостоятельно рисуют себя;
• могут использоваться повторно в любом месте приложения.

Архитектурная схема:

MainWindow
    │
    ├── handle_event()
    ├── update()
    └── draw()
            │
            ▼
        Widget
            │
            ├── handle_event()
            ├── update()
            └── draw()

Такое разделение позволяет полностью отделить интерфейс от логики приложения и обеспечивает повторное использование всех компонентов.
